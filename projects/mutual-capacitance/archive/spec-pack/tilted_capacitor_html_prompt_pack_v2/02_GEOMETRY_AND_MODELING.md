# 几何与建模方向

## 1. 真实运动几何必须先固定
沿用之前 ProxiTouch 的“book-opening”运动逻辑，但这一次它不只是视觉动画，而是正式的研究对象。

真实结构应满足：
- 下电极固定；
- 上电极做纯刚体旋转，不附加平移轨迹；
- 旋转轴沿电极宽度方向；
- 转轴位于初始上下两板之间的中部高度附近；
- 转轴在 x 方向相对电极近边缘存在一个小偏置 δ；
- 这个 x 偏置使得上电极旋转 180° 后与下电极共面，但两者之间保留有限间隙；
- 最终共面间隙与 δ 的关系应由真实几何推导，而不是视觉上手调。

建议统一定义真实几何参数，例如：
- 电极长度 L；
- 宽度 b；
- 初始板间距 D；
- 转轴 x 偏置 δ；
- 展开角 θ；
- 最终共面间隙 g。

具体坐标原点和正方向可自行选择，但全项目必须保持一致。

## 2. 不要把一个解析模型强行覆盖全过程
真实运动从 0° 到 180° 是同一个严格几何；但解析描述可以采用不同层级的近似。

建议思路如下：

### 小角度解析近似
可以把真实偏置转轴在小角度下近似为更简单的“绕电极近边缘旋转”问题，或者在真实几何上做局部一维微元近似。

这里的重点是：
- 明确这是一种有意识的几何/电场近似；
- 说明它为什么在小角度下合理；
- 得到一个简洁可解释的解析关系；
- 可引入对数平均间距等直观等效量，但语言正常，不包装成“技巧”。

请自行重新推导最适合本项目真实几何的表达，不要机械照抄已有公式。

### 理想扇区 / 楔形模型
放在小角度解析之后、完整数值仿真之前最合适。

它的作用主要是：
- 展示非平行等势导体之间，电场线本来就可以是弯曲的；
- 给出一个可以严格解析的理想二维场模型；
- 帮助从“一维局部平行板思维”过渡到“二维电场思维”。

可以研究单扇区或双扇区理想化是否能作为全过程的候选近似，但不要预设它一定在某个角度范围内优于其他模型。真实有限极板有开放端部、有限长度、两侧空间等因素，理想扇区并不等于真实有限结构。

### 完整数值模型
完整二维数值求解应贯穿 0°→180° 全过程，作为统一基准。

数值模型应使用真实旋转几何、有限电极尺寸、真实转轴偏置和最终 gap，而不是另外画一个“差不多”的模型。

## 3. 关键研究问题
Part I 不只是求一条 C(θ) 曲线，还要回答：
- 小角度解析近似什么时候开始明显偏离？
- 理想扇区模型与真实有限极板之间的差异主要来自哪里？
- 正对投影逐渐减小甚至消失后，耦合为何仍然存在？
- 接近 180° 共面状态时，场如何转变为边缘场主导？
- 是否存在一个简单解析近似能覆盖相当宽的角度区间？如果没有，也应如实展示。

## 4. Part II：部分填充介质
在同一真实几何上加入有限尺寸、有限厚度的介质区域。

解析层面可以从“局部空气 + 介质串联”“等效电气厚度”等方法出发，但要自己判断具体几何下怎样处理最合理。

数值层面应求解空间变化的介电常数问题，重点观察：
- 介质边界附近的场重分布；
- 场线是否绕过介质；
- 介质填充比例、位置、εr 对电容的影响；
- 简单等效模型在哪些情况下仍然有效，在哪些情况下误差明显增大。
