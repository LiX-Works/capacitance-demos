# 项目总纲

## 目标
制作一份面向“传感器”课程课堂汇报的交互式 HTML 演示，主题围绕：

**两块平行极板逐渐展开并最终成为共面电极时，电场与电容如何连续变化；解析近似能解释到什么程度；何时需要完整数值仿真；加入部分填充介质后又会发生什么。**

这不是单纯讲公式，也不是单纯展示仿真图。重点是展示一个清楚的建模过程：

**真实几何 → 合理简化 → 解析理解 → 数值仿真 → 对比验证 → 认识模型边界。**

## 内容结构
整体建议分为两个相近权重的 Part：

### Part I：从平行板到共面电极
研究几何变化本身：真实旋转机构、简化解析模型、理想化场模型、完整二维数值解，以及不同模型随展开角变化的适用性。

### Part II：部分填充介质
在同一真实几何上加入有限尺寸/有限厚度介质，继续比较解析等效与数值场求解，研究介质分布如何改变电场和电容。

应用可以在结尾轻量出现，但不是主线。

## 文案与表达风格
- 中文为主，保留必要的英文术语、符号和模型名称。
- 正常、清楚的工科课堂语言，不写成论文腔，也不故意卖弄“技巧”“小聪明”。
- 标题直接说明这一页的问题、动作或结论。
- 一般不使用副标题；确实需要时，副标题字号不能小到像脚注。
- 一页只承担一个主要认知任务。
- 先给物理图像和问题，再给数学；推导只保留真正影响理解的步骤。
- 最终公式应该有，但公式不是页面目的。
- 明确区分：真实几何、解析近似、理想模型、数值结果、仿真结果。
- 不预设某个解析模型在某个区间一定最好，应让数值结果去验证。

## 视觉与交互定位
延续之前已经验证成功的“明亮实验室 + 精密工业模型 + 半透明科学可视化 + 冷蓝场线”方向：
- 明亮蓝灰背景；
- 银蓝色金属电极；
- 半透明介质；
- 清晰的几何尺寸、转轴、角度、场线和曲线；
- 避免暗色赛博朋克、HUD 游戏感、过度玻璃拟态。

3D、动画和定量图表是核心内容，不是装饰。

## 交付形式
最终应为完整、可直接离线打开运行的 HTML 演示。优先单文件离线交付；如确有必要使用资源文件，也要保证整体可便捷打包、移动和运行。
