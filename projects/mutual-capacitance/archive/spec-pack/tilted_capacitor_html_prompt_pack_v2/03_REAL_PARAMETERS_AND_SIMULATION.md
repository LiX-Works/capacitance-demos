# 真实参数、绝对数值与仿真要求

## 1. 必须使用真实参数和真实单位
这次不要只做“任意单位”“归一化场”“示意电容”。

至少应为主要仿真定义真实的：
- 电极长度、宽度、厚度或等效薄片假设；
- 初始板间距；
- 转轴偏置；
- 最终共面间隙；
- 空气介电常数；
- 介质相对介电常数；
- 介质尺寸与位置；
- 激励电压（若数值方法需要）。

最终输出应包含有单位的绝对电容，例如 pF、nF、µF 中合理的量级，而不是只展示 C/C0。

## 2. 但不要为了得到某个漂亮量级强行调参数
用户希望看到“几 µF 之类的真实数值”的感觉，核心诉求是**有单位、可解释、可信**，不是必须做成 µF。

如果合理的空气电容结构自然落在 pF 或 nF，应接受真实结果；不要人为把几何放大到不合理或偷偷加入高 εr 只为了让数值变大。

你可以自行尝试多组真实尺寸和介质参数，选择：
- 工程上合理；
- 数值稳定；
- 曲线变化足够明显；
- 课堂上便于理解；
- 绝对电容量级容易读懂；
的一组作为最终演示参数。

参数选择过程可以多次试算，不必沿用之前讨论中的任何固定数值。

## 3. 2D 与 3D 的单位问题必须处理正确
如果使用二维电场模型，通常得到的是**单位宽度电容**（例如 F/m）。

必须明确：
- 二维求解得到什么物理量；
- 如何乘以真实电极宽度换算成最终 F；
- 何时二维近似合理；
- 如果端部三维效应不可忽略，是否需要用补偿、3D 校验或明确的模型边界说明。

不能把单位宽度结果直接标成总电容。

## 4. 建议的数值验证思路
不要只给最终结果，至少应做若干自检：
- θ→0 时与平行板极限是否一致或接近；
- 网格加密后 C 是否收敛；
- 仿真域扩大后结果是否稳定；
- 电荷法与能量法是否能互相验证（如果实现成本合理）；
- 180° 共面状态是否与成熟的共面条带/边缘场量级一致；
- 有介质时 εr→1 应回到空气结果；
- 介质尺寸趋近于 0 时应回到无介质结果。

## 5. 数值结果展示
建议同时保留：
- 绝对电容 C(θ)；
- 归一化 C(θ)/C0（便于看趋势）；
- 解析近似与数值结果误差；
- 代表性角度下的电势/场强/场线图。

归一化曲线可以有，但不能取代真实单位结果。

## 6. 参数探索由你负责
请把参数选择当作项目的一部分，而不是执行固定表格：
- 先建立合理数量级；
- 快速试扫参数；
- 找到视觉、物理和数值都合适的一组；
- 再固定到最终演示。

如果某个原计划的数值导致场分布、量级或动画不好看，可以改，但要保持物理合理并在文案中自洽。
