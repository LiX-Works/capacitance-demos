# 页面与动画规划

这里的“页面”指 HTML 演示中的场景/知识单元。

建议总长度约 10–12 个主要场景，可自行根据内容合并或拆分，不要机械凑页。

## 建议叙事

### 01｜问题提出
用一个清楚的 3D 动画展示：
平行极板 → 倾斜 → 继续展开 → 共面双电极。

提出问题：
- 电容如何连续变化？
- 电场还是板间均匀场吗？
- 最后没有正对面积，为什么仍有耦合？

### 02｜真实运动几何
用 3D 模型明确：
- 固定电极；
- 旋转电极；
- 转轴；
- 板间中部高度；
- x 方向偏置 δ；
- θ；
- 最终 gap。

应有尺寸和几何标注，动画必须严格遵循真实参数。

### 03｜第一层简化：小角度解析近似
从真实几何过渡到一个便于解析的近似。

重点展示：
- 为什么可以简化；
- 微元如何划分；
- 局部间距如何变化；
- 如何从局部贡献得到整体电容。

推导可以分步动画出现，不要一屏堆完。

### 04｜解析结果与直观等效
把推导整理成更容易理解的等效表达，例如对数平均间距等。

最后回到完整参数形式，给出清楚的结论。

### 05｜理想扇区：电场为什么会弯
从上一页的一维近似提出疑问：真实非平行导体之间电场线是什么样？

通过理想扇区/楔形模型展示：
- 等势线；
- 圆弧或规则弯曲的场线；
- 场强随位置的变化；
- 一个可以严格解析的理想二维例子。

这一页是思想过渡，不是宣布真实结构等于扇区。

### 06｜真实有限电极：数值模型
切回真实有限尺寸、开放边缘、真实转轴与 gap。

展示数值求解区域、边界条件和网格/离散概念，但不要陷入算法细节。

### 07｜连续仿真：θ 扫描
3D 模型旋转与数值场同步：
- 代表性角度场线/电势/场强变化；
- 同步显示 C(θ) 曲线上的当前位置；
- 最好可拖动 θ 交互查看。

### 08｜模型对比
把解析近似、理想扇区候选模型和完整数值结果放到一起。

重点是“哪个模型在哪里解释得好、哪里开始偏离、为什么”，而不是预先指定赢家。

### 09｜加入部分介质
保持同一套真实几何，让介质区域进入模型。

先解释介质位置、厚度、εr 等真实参数。

### 10｜介质的解析近似
从局部串联/等效电气厚度等思路建立可解释模型。

仍然以“理解规律”为目的，不要写成公式墙。

### 11｜介质数值仿真与对比
展示介质边缘附近电场重分布，并与解析等效进行对比。

可以选一组主参数，再补一项简洁参数扫描，例如 εr 或填充比例，不要同时扫太多维度。

### 12｜总结与轻量应用
总结建模方法：
简单结构 → 合理近似 → 数值验证 → 认识模型边界。

应用只需轻量联系：
- 共面电极；
- 接近检测；
- 液位/介质识别；
- 材料检测。

不要让应用抢走“建模 + 仿真”的主线。

## 动画原则
- 动画服务于知识变化，不做无意义 360° 旋转。
- 关键几何变化应连续、可暂停，并有清晰最终帧。
- 3D 几何、公式、曲线和数值场尽可能共享同一 θ 状态。
- 如果图表能随着 3D 旋转同步更新，会比“动画播完后再展示图”更好。
- 场线动画应表达场结构，不要画成自由电荷在空气中流动。
- 代表性阶段可以有相机运动，但相机必须帮助观众看清转轴、间隙、投影关系或介质位置。
