# 使用方式

把本目录中的全部 MD 文件一次性发送给负责正式制作的模型即可。

随后，在聊天输入框中单独发送启动词；启动词不属于项目文件，也不应作为附件或 MD 文件包含在本目录中。

推荐阅读顺序：
1. `01_MASTER_BRIEF.md`
2. `02_GEOMETRY_AND_MODELING.md`
3. `03_REAL_PARAMETERS_AND_SIMULATION.md`
4. `04_HTML_SCENE_AND_ANIMATION_PLAN.md`
5. `05_IMPLEMENTATION_AND_QA.md`

最终交付目标是完整、可离线运行的交互式 HTML 演示。
