# 电容建模实验室｜从平行板到共面电极

## 运行入口

`dist/Capacitance-Lab-offline.html` 是完整单文件版本。脚本、样式、公式引擎和预计算数值数据均已内嵌；运行不需要 Node、Python、CDN 或网络。

请用支持 WebGL2 和 MathML 的桌面浏览器打开，并保持浏览器缩放 100%。本次环境的管理员策略阻止 file:// 与 HTTP 导航，因此没有把这些入口记为已验证通过；实际 QA 使用断网浏览器载入同一份完整 HTML 内容，成功且没有任何外部资源请求。详见 `QA_REPORT.md`。

## 内容与操作

12 个中文场景分为两个各 6 页的部分：几何与场模型、部分介质与验证。它们依次建立固定转轴的真实运动、小角度局部积分、理想扇区、有限电极数值解、模型比较，以及部分填充介质的空间分布与响应。

**Space** 暂停/继续；**→** 完成本页动画，再按进入下一页；**←** 返回当前页起点，再按回到上一页终态；**R** 重播；**P** 自动连播；**E / Esc** 进入/退出探索；**G** 目录；**T** 折叠正文。

探索模式支持 θ 滑条、代表角度、空气/εr=4、场线/电势/场强、全宽视图、相机旋转、滚轮缩放和 HIGH/SAFE。理想扇区不是实际极板等效，因而不与真实极板参数滑条混用。介电常数扫描页使用已实际求解的离散 εr 工况。

## 真实参数与数值边界

统一输入文件：`parameters.json`。主模型 L=20 mm、b=120 mm、初始净间距 D=1 mm、极板厚度 0.1 mm、转轴偏置 δ=1 mm，严格推得最终间隙 g=2δ=2 mm，电势差 1 V。介质位于 x=3–17 mm、y=0.125–0.525 mm，主参数 εr=4，是定义清楚的线性介质模型，并非指定商业材料的认证值。

主曲线来自 44 个角度、空气与介质两组共 88 次二维边界元求解。首先得到 C′（F/m），再乘真实宽度 b，得到页面标明的 C₂D（pF）。例如空气 0° 为 23.3701 pF，180° 为 3.07353 pF；同一几何加入介质后，0° 为 29.8071 pF。

**C₂D 不是完整有限宽度三维电容的精确值。** 另有空气 0°、90°、180° 三个真实 3D 校验点；180° 的有限宽度值约 3.30571 pF，比二维外推高约 7.55%。该差异明确展示，不被隐藏进经验修正因子。未做介质全角度三维验证，也没有实验测量。

默认图形只显示真实宽度中部 28 mm 的剖切窗口，便于看清 1 mm 间隙；没有改变各坐标比例。“全宽视图”显示完整 120 mm，计算结果不随显示模式变化。场线为二维计算截面在三维中的展示；角度非计算节点时明确标注插值，而不是声称实时重解 PDE。

## 构建

使用 Node 22，在 `source/` 执行：

```sh
node scripts/setup-offline.mjs
npm run check
npm run build
npm test
npm run preview
```

包内带有本地重打包的 TypeScript 5.8.3 编译器。上述离线构建不依赖现有 node_modules 或在线 npm。运行成品 HTML 本身不需要编译器。`preview` 默认只监听 localhost:4173。

需要重新计算时，安装 `requirements-reproduce.txt` 中列出的 Python 依赖，执行 `python physics/reproduce.py`，再重新 build。不要只改变 3D 尺寸而不重新生成物理数据。

## 性能说明

当前验证使用 Chromium / ANGLE / SwiftShader 软件渲染，没有实体 GPU。HIGH 场图的实测帧率偏低，SAFE 可减少负担，但不能据此承诺课堂流畅度。完整实测帧率见 QA 报告。演示电脑、投影设备、其他浏览器与系统仍需现场复核。

无字体文件随包分发。公式由本地 KaTeX 输出 MathML，中文和数学字形使用系统字体。
