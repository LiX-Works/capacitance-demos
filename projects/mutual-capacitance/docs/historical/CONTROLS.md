# 操作说明

| 操作 | 行为 |
|---|---|
| Space / 暂停按钮 | 暂停当前动画；再次继续。终态时重新播放本页 |
| → / 下一步 | 动画未完成时立即完成；终态时进入下一页 |
| ← | 回到当前页稳定起点；已在起点时回到上一页终态 |
| R | 重播当前页，不改物理参数定义 |
| P / 连播 | 开启或关闭整段连续播放，使用原有动画时长而非加速跳页 |
| Home / End | 第一页起点 / 最后一页终态 |
| E / 探索 | 进入以同一几何参数驱动的探索模式 |
| Esc | 关闭对话框；退出探索并恢复原页面、相位与相机 |
| G | 打开目录，可直接跳至任一场景 |
| T / 正文折叠按钮 | 折叠或恢复原理说明 |
| 全屏 | 请求浏览器全屏；具体权限由浏览器决定 |

## 探索模式

θ 滑条范围 0°–180°，步长 0.25°。显示的角度直接驱动固定轴的刚体旋转。0°、30°、90°、180° 按钮选择已求解的角度节点。非节点时，界面明确显示插值区间。

“加入 εr=4 介质 / 改为空气”改变实际介质显示与同一参数几何的数值数据；不会修改板长、间距或转轴。场线、电势与场强按钮切换实际求解数据的展示方式。场强颜色有公开的上下限，不能用显示饱和峰值判断材料击穿。

“全宽视图”显示实际 120 mm 宽度；默认剖切窗口只用于观察，不参与电容换算。探索时在模型区域拖动可旋转相机，滚轮可缩放。更换视图或角度会恢复适合当前几何的自动构图。

选择 HIGH / SAFE 调整渲染负担，不改变任何物理参数或数值曲线。按 Esc 返回演示。输入框拥有焦点时，普通快捷键不会抢占输入；Esc 仍可退出。

理想扇区页具有不同边界条件，真实极板 θ 和介质控制在该页停用。εr 扫描页的 θ 固定为 0°，通过重播查看七个已求解工况；不伪装成任意材料参数的实时仿真。
