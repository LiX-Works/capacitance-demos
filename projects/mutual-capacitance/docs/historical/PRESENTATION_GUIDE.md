# 课堂演示指南

先打开单文件 HTML，使用 100% 浏览器缩放。推荐 1920×1080 或 2560×1440。实体 GPU 与投影表现尚未在本次环境验证，请先确认文件入口、图形加速与字体。

## 讲解主线

前半部分先让观众看见连续展开，再固定几何关系。第二页强调：轴的位置不变，上板只有旋转，最终 g=2δ 是几何推导，不是动画调出来的距离。第三页把局部窄条的电容相加；讲清楚“保留几何、近似电场”，不要把近似曲线称为真实结构的精确解。

理想扇区页用于解释弯曲场线。它的绝缘径向边界与真实有限电极不同，应明确告诉观众为什么“能严格解析”不等于“能准确等效当前器件”。随后回到有限极板的数值扫描，用曲线比较模型适用范围。

后半部分固定介质的真实位置、厚度和 εr，先建立局部空气/介质串联的电气厚度，再看数值场如何绕过介质边缘。εr 扫描保持 θ=0°，每个点都对应实际求解。结尾强调收敛误差、二维宽度近似和实验误差是三件不同的事。

## 回答可能的问题

“最后没有正对面积，为什么还有电容？”——进入第 06 页，拖到 180°，让观众看外围耦合与非零电容。局部公式失去适用条件，不等于真实电容归零。

“这个 pF 是整个器件的电容吗？”——主值明确为 C₂D=bC′ 的绝对外推值。第 11 页列出有限宽度 3D 校验点；180° 约 3.30571 pF，而二维外推约 3.07353 pF。

“介质只是让电容乘 εr 吗？”——不是。这里只部分填充，存在空气串联与边缘绕行；查看第 08–10 页，比较局部模型与真实空间 ε(x,y) 数值解。

“屏幕上每一个角度都重新解方程吗？”——不是。预计算的 44 个角度节点是独立求解；其他角度明确插值。HTML 不在课堂临时求解 PDE。

“为什么默认看起来不是 120 mm 宽？”——默认仅观察中部 28 mm 剖切段。点全宽显示实际完整比例；前后 C 的读数严格相同。

完整推导与数值收敛数据随包提供。不要把模拟数据解释成加工、测量、认证材料或实验验证结果。
